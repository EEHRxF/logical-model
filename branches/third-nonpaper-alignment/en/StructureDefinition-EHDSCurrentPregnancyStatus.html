Logical Model: Current pregnancy status model

Official URL: http://ehds.eu/fhir/models/StructureDefinition/EHDSCurrentPregnancyStatus Version: 0.3.0
Draft as of 2026-11-17 Computable Name: EHDSCurrentPregnancyStatus

EHDSCurrentPregnancyStatus means a structured set of data elements describing a patient's pregnancy status at a given point in time.

Usages:

  • Use this Logical Model: Imaging report model. and Patient summary model
