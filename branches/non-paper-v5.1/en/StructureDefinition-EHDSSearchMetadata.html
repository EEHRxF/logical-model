Logical Model: Data group search metadata model

Official URL: http://ehds.eu/fhir/models/StructureDefinition/EHDSSearchMetadata Version: 0.3.0
Draft as of 2026-11-21 Computable Name: EHDSSearchMetadata

Metadata for searching individual data groups, based on WP v5 Annex III and the final review instructions. This model is independent of the resource-content model EHDSDataSet.

Usages:

  • Derived from this Logical Model: Document search metadata model
