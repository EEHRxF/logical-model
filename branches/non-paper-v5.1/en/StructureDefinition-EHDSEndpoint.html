Logical Model: Endpoint model

Official URL: http://ehds.eu/fhir/models/StructureDefinition/EHDSEndpoint Version: 0.3.0
Draft as of 2026-11-21 Computable Name: EHDSEndpoint

EHDSEndpoint means a structured set of data elements describing the technical details of a connection point for electronic services.

Usages:

  • Use this Logical Model: Imaging study model.

You can also check for usages in the FHIR IG Statistics

EHDSEndpoint 0..* Base Endpoint model
EHDSEndpoint.identifier 1..* Identifier Identifier for the endpoint.
EHDSEndpoint.status 1..1 CodeableConcept Status of the endpoint, e.g. active, limited.
Binding Description: (required) ⚠: HL7 Endpoint Status
EHDSEndpoint.connectionType 1..* CodeableConcept A coded value identifying the technical protocol, profile or standard used to connect to and communicate with the endpoint.
Binding Description: (required) ⚠: HL7 Endpoint Connection Type
EHDSEndpoint.name 0..1 string A friendly name that this endpoint may be referred to with.
EHDSEndpoint.managingOrganisation 0..1 EHDSOrganisation The organisation that provides technical management services for this endpoint.
EHDSEndpoint.payload 0..* Base The set of payloads that are provided/available at this endpoint.
EHDSEndpoint.payload.mimeType 0..* CodeableConcept The MIME type to send the payload in (e.g. application/fhir+xml, application/fhir+json).
Binding Description: (required) ⚠: BCP 13
EHDSEndpoint.payload.profileCanonical 0..* uri The technical profile that is required at this endpoint. It describes the resources that are handled, or even simply which resource types.
EHDSEndpoint.payload.profileUri 0..* uri The profile (as a uniform resource identifier (URI)) that is required at this endpoint when not represented using an FHIR profile.
EHDSEndpoint.address 1..1 uri The URI that describes the actual endpoint to connect to.
EHDSEndpoint.header 0..* string Additional headers/information to send as part of the notification. Usage depends on the channel type.
